# WordLink

영어 단어 카드를 조합해 목표에 도달하는 오프라인 Flutter 퍼즐입니다. 목표, 재료, 조합 결과, 힌트는 영어로 표시됩니다.

| 모드 | 문제 수 | 조합당 카드 | 목표까지 필요한 성공 조합 |
|---|---:|---:|---:|
| Easy | 10,000 | 4장 | 10회 |
| Normal | 10,000 | 8장 | 15회 |
| Hard | 10,000 | 16장 | 20회 |

난이도마다 15개 테마와 테마당 666~667개 변형을 담았습니다. 각 테마는 중간 결과 5곳에 대체 조합을 두어 32개의 경로를 만들며, 세 난이도에 중간 결과 순서가 다른 경로가 총 1,440개 있습니다. 문제는 번호나 영어 목표 단어로 검색할 수 있습니다.

## 실행

```sh
flutter pub get
flutter devices
flutter run
flutter test
```

1. 보유 카드에서 지정된 수만큼 선택하고 **조합하기**를 누릅니다. 작업대에서도 카드 선택을 해제할 수 있습니다.
2. 성공하면 선택한 카드를 소진하고 결과 카드와 새 후보 카드를 받습니다. 고르지 않은 카드는 남습니다. 결과 카드는 다음 조합에 들어갑니다.
3. 실패하면 카드와 현재 단계가 유지됩니다. 필요한 경우 **이번 조합 힌트**에서 영어 카드 이름을 확인하세요.
4. 상단의 다시 시작 버튼으로 같은 문제의 첫 단계부터 다시 시작합니다.

## 프로젝트 구조

```text
android/                           Android 실행 프로젝트
ios/                               iOS 실행 프로젝트
assets/stages.json                  영어 카드 사전과 30,000개 퍼즐 검색 목록
assets/puzzles/                     테마별 사전 구축 레시피 묶음 45개
assets/embeddings.json              카드별 샘플 벡터
lib/main.dart                       앱과 ProviderScope
lib/models.dart                     Stage, PuzzleRound, WordItem, CombinationRule, CraftOutcome
lib/local_knowledge_service.dart    에셋 로딩, 조합 검증, 코사인 근접도
lib/game_controller.dart            Riverpod 인벤토리, 시도 기록, 리셋
lib/game_screen.dart                플레이, 문제 검색, 조합 이펙트

tool/build_campaign.py              오프라인 캠페인 생성기
```

## 캠페인 데이터

`python3 tool/build_campaign.py`로 번들 에셋을 다시 생성합니다. 테마별 기본 경로와 대체 중간 결과는 생성기에서 정의합니다. 각 경로에 들어갈 재료와 후보 카드 구성은 고정 시드로 생성합니다. 앱은 검색 목록과 벡터를 먼저 읽고 플레이에 필요한 테마 레시피 묶음 하나만 열어 캐시합니다. 앱은 생성기나 외부 API를 호출하지 않습니다.

- `words` 행은 영어 이름, 이모지, 속성을 저장합니다.
- `stages` 행은 난이도, 목표 카드 ID, 레시피 묶음 번호, 묶음 내부 인덱스를 저장합니다. 카드 ID는 `words`의 인덱스입니다.
- `assets/puzzles/<번호>.json` 행은 퍼즐의 라운드 목록입니다. 라운드 행은 결과 카드 ID, 필요한 새 카드 ID 목록, 그 외 후보 카드 ID 목록을 담습니다. 두 번째 라운드부터는 직전 결과 카드도 레시피에 필요합니다.
- 샘플 벡터는 카드를 테마와 진행 단계에 따라 표현합니다. 앱은 코사인을 0~100으로 표시하고, 스테이지의 사전 구축 레시피로 성공을 판정합니다.
- 모든 조합 시도는 기록과 별점에 반영됩니다. 기준 이하면 3성, 기준보다 1~2회 많으면 2성, 그 이상이면 1성입니다.

# WordLink

## 단어 추리

홈의 기본 모드입니다. 정답은 `???`로 숨겨져 있으며, 영어는 ABC순, 한국어는 가나다순으로 정렬한 16장의 시작 카드에서 두 장을 골라 조합합니다. 작업대 목록은 최대 16장을 보여주며, 보관 카드는 다시 꺼낼 수 있습니다. 모든 시작 카드는 해당 목표와의 유사도가 10% 이상입니다. 검토된 오프라인 레시피에서 두 재료와 연결되는 결과를 조회합니다. 관련 결과가 없으면 다른 카드로 다시 시도할 수 있습니다. 생성한 단어는 다음 조합에 재사용할 수 있습니다. 힌트는 재료 하나만 보여줍니다. 일부 정답은 같은 중간 결과를 여러 갈래에 재사용하거나 다른 재료 경로로 만들어 낼 수 있습니다. 정확히 정답을 만들거나 단어 입력으로 맞히면 100%가 표시됩니다.

쉬움·보통·어려움마다 10,000문제가 들어 있습니다. 각각 목표 단어 45·42·44개에 시작 재료와 만들 수 있는 함정 경로가 다른 구성을 적용합니다. 모든 구성에서 시작 카드만으로 정답과 한 가지 이상의 함정 단어를 만들 수 있도록 생성 단계에서 검사합니다. 총 8,020개 문제에서는 같은 정답에 이르는 경로가 둘 이상 열려 있습니다. 친구 출제는 선택한 난이도에서 도달 경로가 확인된 단어를 받습니다.

`assets/inference/lexicon.json`의 두 언어 단어와 연쇄 조합을 편집한 뒤 `python3 tool/build_inference_puzzles.py`를 실행하면 문제 묶음을 재생성할 수 있습니다. 의미 기반 후보 작성과 채점에는 [오프라인 작성 프롬프트](tool/inference_recipe_prompt.md)를 사용합니다. 로컬 모델 명령이 표준 입력으로 프롬프트를 받고 표준 출력으로 JSON을 반환한다면 다음과 같이 후보를 검토할 수 있습니다.

```sh
printf '%s\n' '[[["Magnet","자석"],["Needle","바늘"]]]' | python3 tool/review_inference_recipes.py ./local-model-command
```

검토기는 배치 안에서 입력 순서가 뒤집힌 요청과 승인 실패 결과도 캐시합니다. 승인 결과를 편집자가 확인한 뒤 `semanticRecipes`에 저장하면 앱에서 사용할 수 있습니다.

## 카드 캠페인


단어 카드를 조합해 목표에 도달하는 오프라인 Flutter 퍼즐입니다. 홈에서 한국어 또는 English를 선택하면 목표, 재료, 조합 결과, 단서, 기록도 같은 언어로 표시됩니다.

| 모드 | 문제 수 | 조합당 카드 | 목표까지 필요한 성공 조합 |
|---|---:|---:|---:|
| Easy | 10,000 | 2장 | 10회 |
| Normal | 10,000 | 3장 | 15회 |
| Hard | 10,000 | 4장 | 20회 |

난이도마다 15개 테마와 테마당 666~667개 변형을 담았습니다. 각 테마는 중간 결과 5곳에 대체 조합을 두어 32개의 경로를 만들며, 세 난이도에 중간 결과 순서가 다른 경로가 총 1,440개 있습니다. 기본 카테고리는 All입니다. 카테고리를 바꾸거나 상단의 랜덤 새 문제 버튼을 누르면 선택한 범위에서 다른 테마의 문제가 나옵니다.

## 실행

```sh
flutter pub get
flutter devices
flutter run
flutter test
```

1. 보유 단어는 한 줄에 네 장씩 이어집니다. 위아래로 밀어 보거나, 카드 모서리의 손잡이를 바로 끌거나 카드 본문을 잠깐 눌러 작업대에 놓을 수 있습니다. 카드를 탭해 선택하는 것도 가능합니다. 필요한 수를 채운 뒤 **조합하기**를 누릅니다.
2. 성공한 레시피는 중간 결과와 새 후보 카드를 엽니다. 사용한 카드는 소진되고, 새 단계마다 보유할 수 있는 카드가 늘어납니다.
3. 다른 조합도 재료 이름에서 파생된 영어 단어를 만듭니다. 파생 카드가 사용한 필수 재료 하나를 대신하며, 나머지 필수 재료는 보충됩니다. 보유 단어 아래의 **조합 단서**에서는 필요한 카드 수와 속성을 볼 수 있습니다. 숨겨진 조합은 2~4장으로 시도할 수 있습니다.
4. 첫 홈 화면에서 화면과 퍼즐 단어를 한국어 또는 English로 바꿀 수 있습니다.
5. 상단의 도감에서 발견한 단어와 숨겨진 조합 보상을 볼 수 있습니다. 별점과 최소 시도 기록은 기기에 저장됩니다.
6. 상단의 랜덤 버튼은 새 문제를 엽니다. 작업대의 조합 리셋은 같은 문제의 첫 카드와 시도 횟수로 되돌립니다. 저장된 도감과 개인 기록은 유지됩니다.

## 캠페인 데이터

`python3 tool/build_campaign.py`로 번들 에셋을 다시 생성합니다. 테마별 기본 경로와 대체 중간 결과는 생성기에서 정의합니다. 각 경로에 들어갈 재료와 후보 카드 구성은 고정 시드로 생성합니다. 앱은 퍼즐 목록과 벡터를 먼저 읽고 플레이에 필요한 테마 레시피 묶음 하나만 열어 캐시합니다. 캠페인 단어가 바뀌면 `tool/word_labels_ko_terms.json` 사전을 보완하고 `python3 tool/build_korean_labels.py`를 실행합니다. 앱은 생성기나 외부 API를 호출하지 않습니다.

- `words` 행은 영어 이름, 이모지, 속성을 저장합니다.
- `stages` 행은 난이도, 목표 카드 ID, 레시피 묶음 번호, 묶음 내부 인덱스를 저장합니다. 카드 ID는 `words`의 인덱스입니다.
- `assets/puzzles/<번호>.json` 행은 퍼즐의 라운드 목록입니다. 라운드 행은 결과 카드 ID, 필요한 새 카드 ID 목록, 그 외 후보 카드 ID 목록을 담습니다. 두 번째 라운드부터는 직전 결과 카드도 레시피에 필요합니다.
- 샘플 벡터는 카드를 테마와 진행 단계에 따라 표현합니다. 앱은 코사인을 0~100으로 표시하고, 스테이지의 사전 구축 레시피로 성공을 판정합니다.
- 모든 조합 시도는 기록과 별점에 반영됩니다. 기준 이하면 3성, 기준보다 1~2회 많으면 2성, 그 이상이면 1성입니다.
